# 凡氏可行 | 地下會社

「地下會社」暗黑風格銷售頁，為 1 對 1 諮詢展示情境設計。

內容由關係共鳴、拆局方法、全年會員內容、加入前後轉變、方案比較與常見問題組成，並支援桌面及手機版。

## 本機啟動

```bash
pnpm install
pnpm dev
```

開啟 `http://localhost:3000`。

## 正式建置

```bash
pnpm build
pnpm start
```

## 主要檔案

- `app/page.tsx`：銷售頁內容與互動
- `app/globals.css`：暗黑酒紅視覺與響應式版面
- `app/layout.tsx`：網站標題與描述
